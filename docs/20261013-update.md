# 2026-10-13 홈페이지 보강 및 운영 인계

## 변경 범위

- 기존 KENTECH 로고, 남색·녹색 디자인, 기존 공개 캠퍼스 이미지 유지.
- 메뉴: 센터 소개, 연구·기술, 주요사업, 소식·활동, 문의.
- `/ko`와 `/en`에 각각 8개 페이지. 나주와 강진은 프로젝트 상세 페이지로 분리.
- `lib/content.ts`에서 같은 항목의 국문·영문을 함께 관리. 신규 콘텐츠는 양쪽을 동시에 검토.
- 언어 전환은 같은 경로의 대응 페이지로 이동. HTML lang, 제목, canonical, hreflang, sitemap 반영.
- 예전 주소는 `next.config.ts`에서 대응 페이지로 영구 리디렉션.
- 임시 연락처·XX 성과·지난 공개 예정 문구·제작 설명 삭제.
- 확인되지 않은 기관 역할, 교수진 관계, BIXPO 세부사항은 공개 문구에서 제외.
- 성능·감축 목표 수치는 게시하지 않음. 나주 일정은 2026년 10월 기준 계획으로 표시.
- 내부 사업계획서와 사진 원본은 저장소에 추가하지 않음.

## 게시 콘텐츠와 확인 대기 항목

공개 문구는 사용자 인계 및 사용자 승인된 보완안을 기반으로 작성했다. 사업계획서의 상세 설계값·도면은 게시하지 않았다. 강진 페이지는 2026-10-01 운영자료의 원료·운전 방식·기간 요약만 사용하며 나주 실적과 분리했다.

후속 확인: 센터 공식 명칭·설립 목적, Circular Bioeconomy Lab 및 각 대학·한전 부서와의 관계, May Project의 정확한 뜻, BIXPO 행사 자료, 기관 로고 사용 가능 여부, 나주/강진 공개 가능한 실제 사진, 국문·영문 검토 담당자. 현재의 교수진·기관 역할 확대는 확인 후 반영한다.

센터 주소와 `bioupcycling@kentech.ac.kr`은 기존 공개 사이트의 정보를 유지했다. 실제 수신 여부는 검증하지 않았다. 전화번호 및 별도 기업 메일은 확인 전 노출하지 않는다.

## 문의 폼

`RESEND_API_KEY`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL` 세 환경변수가 빌드 시 모두 설정된 경우에만 문의 폼을 표시한다. 미설정이면 이메일 안내를 표시한다. 변수는 Vercel에서 관리하며 저장소에 기록하지 않는다. 변수 변경 후 재배포해야 화면이 갱신된다.

실제 이메일 발송은 테스트하지 않았다. 서버의 기존 필수값·이메일 검증·honeypot·rate limit을 유지했다. Resend가 오류 객체를 반환하면 성공으로 표시하지 않도록 수정했다.

## 백업 및 복구

원본 커밋: `b70b57250b564f1e33890c50229a221259f127c2` (`master`). 작업 시작 시 원격 HEAD와 원본 로컬 소스가 일치했고 변경 파일은 없었다.

작업 폴더 상위의 `backups/bioupcycling-before-20261013.bundle`은 모든 원격 이력을 포함하는 Git 백업이며 `git bundle verify`에 통과했다. `backups/bioupcycling-before-20261013.zip`은 해당 커밋의 전체 추적 소스와 공개 자산이다. Vercel 환경변수·계정 설정은 포함하지 않으며 이번 작업에서 변경하지 않았다.

빠른 복구는 Vercel의 이전 정상 배포를 운영 배포로 되돌리는 방식이다. 소스 복구가 필요하면 업데이트 커밋을 `git revert`하여 기존 `master`에 반영한다. 강제 push 또는 작업 중인 파일에 대한 `reset --hard`는 사용하지 않는다. 원본 파일을 독립 폴더에서 확인하려면 `git clone <bundle 경로> <새 복구 폴더>` 후 원본 커밋을 체크아웃한다.

## 로컬 실행

`npm ci`, `npm run build`, `npm run start -- --port 3100` 순서로 실행한다. 브라우저에서 `http://localhost:3100/ko`를 연다. `node scripts/check-site.mjs`로 언어별 페이지, 기존 주소, 메타데이터, 누락 경로, 문의 필수값 검증을 확인한다.

Next.js와 eslint-config-next는 16.4.0, PostCSS는 8.5.30으로 갱신했다. 원래 배포 의존성에서 발견된 보안 수정과 함께 lockfile을 업데이트했다. 남은 개발 도구 전용 감사 결과는 검수 기록에 구분한다.
